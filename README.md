# English Loop

Next.js + Supabase learning platform.

## Setup

1. Install dependencies
2. Copy `.env.example` to `.env.local`
3. Add Supabase URL and anon key
4. Run `npm run dev`

## Deploy

Connect this repository to Vercel and add the same environment variables.

## Features

- Student dashboard
- Teacher review flow
- Speaking practice
- Progress tracking
